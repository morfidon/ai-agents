# Feature Exploration

## Explore one opportunity

1. Choose an audience and a task grounded in project docs, feedback supplied by the user, or an existing flow. Mark assumptions about demand and effort.
2. Identify the gap in the current experience. For a deep pass, propose five to ten distinct ideas. For a short pass, limit the set to three. Vary the interaction or outcome so the ideas can be compared.
3. Sketch the central screen, flow, API interaction, or gameplay loop for each idea in prose or a compact diagram. State who benefits, the dependency or constraint that matters most, and what would make the idea worth pursuing.
4. Compare the directions by user value, implementation effort, and confidence. Recommend one direction and describe a small way to validate it. Keep mockups in the response and leave the repository untouched.
